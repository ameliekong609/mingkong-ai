## Agentic Accountant Copilot

### Purpose

Explore controlled agentic systems for financial-statement preparation.

### Core ideas

- persistent digital workers
- Hermes-based runtime
- Codex CLI execution worker
- agentic planning
- specialist agents
- evidence registry
- source-of-truth separation
- bounded senior-review and correction loops
- deterministic controls
- human approval
- release gates
- long-running task recovery
- structured workbooks and evidence-linked outputs

### Repository

https://github.com/ameliekong609/Agentic-accountant-copilot

### Important distinction

This is not a fixed step-one-to-step-five LLM workflow.

It is designed around delegated work, investigation, tool use, review, correction and controlled release.
